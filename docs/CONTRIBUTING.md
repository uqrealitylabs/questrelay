# Contributing

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all project spaces.

## Contribution Process

1. Find an open issue to work on. If none fits, create one with the result you want.
2. Create a separate branch for the issue, such as `fix-camera-tracking`.
3. Make the smallest focused change that solves the issue. Keep unrelated files and generated output out of the diff.
4. Check that the change works.
5. Open a pull request that links the issue and briefly says what changed and how you checked it.

Keep the change understandable, explainable, and easy to review. Ask in the project channel if you are blocked.
