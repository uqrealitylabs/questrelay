The first QuestRelay room was a place to work out how watching several headsets should feel in a browser. The web app moved into `frontend/`, and the audience page gained a headset lounge, a main viewing area and controls that made sense even with several tiles on screen

### In the room

- Choose which headset to watch, focus one feed or start watching every available feed
- Adjust theme, density and accent in the room settings, with preferences saved in that browser
- See a useful empty state and automatic retry message when the headset list cannot load

This version was about the viewing interaction. It predates the Rust relay and the Quest capture app, so there was no headset-to-browser media path to package as a container yet
