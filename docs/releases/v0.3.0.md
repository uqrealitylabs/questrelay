The headset side and the viewing room first met at the Rust API in this version. A publisher can send H.264 and Opus RTP packets over an authenticated WebSocket. The relay hands the tracks to mediasoup for WebRTC viewers

Room access stopped being a single shared viewer key. The API exposes room information and issues short-lived, single-use tickets after checking a public room or its private access code. Admin sign-in and room settings live on separate endpoints, with access attempts limited and persisted settings loaded on restart

The repository layout also moved towards `frontend/`, `backend/` and the Quest work area. The full companion app UI and installable APK arrived later
