The v0.8.1 images had to be rebuilt with missing Docker build inputs supplied by a backfill job. This release carries those repairs in the Dockerfiles themselves. The Rust builder installs `rustfmt`, which mediasoup needs while generating code. The web builder copies the shared TypeScript config before compiling the room

The release workflow checks the web app, Rust relay, Quest app and deployment files, then publishes two GHCR images from this tag:

```text
ghcr.io/uqrealitylabs/questrelay-backend:v0.8.2
ghcr.io/uqrealitylabs/questrelay-frontend:v0.8.2
```

The downloads below include a Linux x86_64 relay binary, a Quest debug APK for ADB testing and SHA-256 checksum files. The Quest package still needs a separate signed build for a normal Meta release channel

No streaming protocol or room behaviour changed. The relay remains self-hosted while Cloudflare Realtime integration is being built. The [deployment guide](https://github.com/uqrealitylabs/questrelay/blob/v0.8.2/docs/DEPLOY.md) explains the server keys, HTTPS and direct media port
