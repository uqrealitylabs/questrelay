# QuestRelay releases

These releases follow QuestRelay as the web room, Rust relay and Quest app came together. `v0.8.0` is the first tag with matching version numbers across those components. For a build you can install or deploy, start with the latest release

| Version | Source milestone | What changed |
| --- | --- | --- |
| `v0.1.0` | `cb8a13e` | Reshaped the first QuestRelay web experience |
| `v0.2.0` | `41e5dbb` | Added the Rust WebRTC relay |
| `v0.3.0` | `392884c` | Connected Quest ingest, room access and the relay API |
| `v0.4.0` | `132ff2c` | Built the public viewer and separate admin control room |
| `v0.5.0` | `8d98ce5` | Gave Mochi more expressive interactions |
| `v0.6.0` | `cc23de4` | Added the Quest capture app, release tooling and deployment groundwork |
| `v0.7.0` | `2d8edad` | Made CI selective and organised deployment scripts and documentation |
| `v0.8.0` | Release prep | Synced component versions and added GHCR image publishing. A tag-only CI bug blocked the original image run |
| `v0.8.1` | Current release | Isolated path-filter fixtures from tag CI so the image workflow can complete |

All versions remain pre-1.0. The [current status](../README.md#current-status) describes what has been tested on a real Quest and what still needs field validation
