# QuestRelay releases

These releases follow QuestRelay as the web room, Rust relay and Quest app came together. `v0.8.0` is the first tag with matching version numbers across those components. For a build you can install or deploy, start with the latest release

| Version | Source milestone | What changed |
| --- | --- | --- |
| [v0.1.0](releases/v0.1.0.md) | `cb8a13e` | Reshaped the first QuestRelay web experience |
| [v0.2.0](releases/v0.2.0.md) | `41e5dbb` | Added the Rust WebRTC relay |
| [v0.3.0](releases/v0.3.0.md) | `392884c` | Connected Quest ingest, room access and the relay API |
| [v0.4.0](releases/v0.4.0.md) | `132ff2c` | Built the public viewer and separate admin control room |
| [v0.5.0](releases/v0.5.0.md) | `8d98ce5` | Gave Mochi more expressive interactions |
| [v0.6.0](releases/v0.6.0.md) | `cc23de4` | Added the Quest capture app, release tooling and deployment groundwork |
| [v0.7.0](releases/v0.7.0.md) | `2d8edad` | Made CI selective and organised deployment scripts and documentation |
| [v0.8.0](releases/v0.8.0.md) | Release prep | Synced component versions and added GHCR image publishing. A tag-only CI bug blocked the original image run |
| [v0.8.1](releases/v0.8.1.md) | Backfilled release | Fixed tag-only CI path selection and backfilled the missing images and downloads |
| [v0.8.2](releases/v0.8.2.md) | Current release | Put the Docker build repairs into the tagged source so normal release publishing works |
